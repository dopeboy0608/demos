## 결정 로그

- 패딩 제거 범위: `region-view`의 `margin: -24px` 네거티브 마진 패턴을 그대로 재사용해 `AppLayout` Content 패딩까지 상쇄. 로고/Gnb/Util/Recruit 등 고정 UI는 `xmark-stage` 내부 모서리 배치 그대로 유지.
- 리스트 모드: 완전 삭제(비활성화가 아님) — `XmarkStyleTabs`/`XmarkPortfolioList`/`XmarkListRow`/`getListMaxScroll` 등 전체 제거.
- 카드 수: `XMARK_GALLERY_PAGE_SIZE` 12 → 10.
- 최소 카드 크기: 사용자가 구체적 수치를 지정하지 않고 "합리적 기본값으로 진행"을 선택 → 01 구현 시 임의로 정하고 화면으로 검증받음. 그 이하 해상도에서는 브라우저 뷰포트 스크롤을 허용(페이지 자체 스크롤이 아님).
- 마우스 3D 패럴럭스 세부 수치(최대 회전각 등): 사용자가 "임의로 적당히 정해서 진행"을 선택 → 03 구현 시 정하고 화면으로 검증받음.
- PoC 재사용: 실제로는 `XmarkGalleryEntrancePoc`가 마우스 추적과 무관한 entrance 전용 데모라 프로토타입 용도로 쓰지 않고, 실제 `XmarkGalleryGrid`에 바로 구현 후 브라우저로 직접 검증함(03 종료 시 결정). `/xmark-poc` 라우트는 기존 역할(entrance 데모) 그대로 유지하고 삭제하지 않음.
- 휠 방향: 기존 "휠업=다음 페이지 / 휠다운=이전 페이지" 자체는 유지. 등장/퇴장 방향(위/아래)만 신규 요구사항대로 변경.

## 발견 사항 (③ 스펙-코드 불일치, 스토리 본문은 건드리지 않음)

- 이슈 본문은 마우스 3D 회전에 대해 "원본 코드 참고"라 적었지만, 실제 코드(`src/features/xmark/`)에는 마우스 추적(`mousemove`/`pointermove`) 기반 회전 로직이 전혀 없음 — GSAP 타임라인 기반의 고정된(클릭/라이프사이클 트리거) 회전만 존재. 03에서 새로 설계 필요.
- `XmarkGalleryGrid.tsx:72-95`의 기존 진입(enter) 애니메이션은 이미 `y: ENTER_START_Y → 0` 수직 이동을 포함하고 있음. 그러나 이슈 작성자는 "현재는 제자리에서 회전임"으로 기억 — 실제 `ENTER_START_Y` 오프셋이 뷰포트 아래 기준이 아닐 가능성이 있어, 02에서 가치를 재검토하고 "뷰포트 아래에서 시작"으로 명확히 재조정함.

## 진행 로그

- 01(#73) 완료(44563e9): `region-view`의 `margin:-24px` 패턴 대신, `.xmark-content`에 포트폴리오 탭 전용 `--full` 모디파이어(패딩 0, overflow hidden)를 추가하고 `.xmark-portfolio`/`.xmark-gallery-area`를 flex 레이아웃으로 바꿔 5열x2행(최소 150x170px) 그리드가 flex:1 영역을 꽉 채우도록 구현. 리스트 모드 전체 삭제, 페이지 크기 10으로 변경. 1440x900에서 스크롤 없이 10장 모두 노출, 900px 폭/500px 높이 등 좁은 뷰포트에서는 각각 가로/세로 스크롤(후자는 `.xmark-stage`의 `min-height:720px` 덕분에 AppLayout Content 레벨에서 자연스럽게 발생)로 폴백됨을 브라우저로 확인. 다른 라우트(/, /region-view, /vonin) 회귀 없음. lint/tsc/test(83개) 통과.
- 02(#74) 완료(2306ca4): `XmarkGalleryGrid`의 등장 `gsap.set` y값을 고정 60px 대신 함수형 값(`window.innerHeight - target.getBoundingClientRect().top + 40`)으로 바꿔, 그리드의 몇 번째 행이든 모든 카드가 뷰포트 하단 바깥에서 올라오도록 수정. 브라우저로 애니메이션 중간 프레임(카드가 화면 밖에서 올라오는 모습)과 최종 정착 상태를 확인.
- 03(#75) 완료(63aa032): `perspective`를 `.xmark-gallery-grid`에서 부모 `.xmark-gallery-area`로 옮기고 그리드에 `transform-style:preserve-3d` 추가. `window`의 `mousemove`를 구독해 컨테이너 중심 대비 포인터 오프셋을 -1~1로 정규화한 뒤 `gsap.quickTo`로 rotationX/rotationY를 최대 ±12도까지 부드럽게 따라가도록 구현(피벗은 transform-origin 기본값인 중앙 유지). 브라우저에서 그리드 좌상단/우하단으로 마우스를 옮겨 반대 방향으로 기울어짐을 확인.
