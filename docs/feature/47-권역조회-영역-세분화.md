## 결정 로그

- **줌 레벨 임계값**: 지도 중심이 서울시청(`CITY_HALL`)일 때 기준으로, 레벨 8 이상=기본(센터),
  6~7=소분류, 5 이하=세분류. 레거시(`ZOOM_LEVEL_REGION=6`/`ZOOM_LEVEL_REGION_SUB=4`) 비율을
  참고해 이 프로젝트의 `maxLevel=12` 스케일에 맞게 재설정.
- **센터 기본 영역 크기**: 반경 약 8~10km(기존 ≈2.2km 대비 약 4배 확대).
- **분할 모양**: 각도(부채꼴) 분할 — 센터/소분류 중심에서 방사형으로 균등 분할.
- **세분류 개수 분배**: `subRegionCount`(센터 전체 기준)를 소분류별로 시드 기반 임의 분배
  (결정적 의사난수, `createNaturalPolygon`과 동일한 방식).
- **색상/라벨**: 소분류/세분류 폴리곤은 상위 센터 색상을 그대로 상속(별도 팔레트 없음).
- **범위**: 블록(최세밀) 단위는 다루지 않는다(레거시엔 있었으나 이 프로젝트 범위 밖). 실제
  백엔드 API 연동도 범위 밖(계속 프론트엔드 목업).
- Cross-check gate: 디자인 파일 없음(n/a), 코드 교차검증 결과 블로킹(①/②) 항목 없음, 다른
  활성 브랜치와 `region-view` 파일 충돌 없음 → 게이트 통과(재검증 불필요).
