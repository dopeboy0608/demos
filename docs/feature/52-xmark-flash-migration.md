## 사실 조사 / 발견 사항 (Phase B)

- `src/features`에 "xmark" 네이밍 충돌 없음
- `gsap`는 이미 설치됨(`^3.15.1`, #12에서 설치) — 재사용 가능
- `sub-task` 라벨 기존 존재(이슈 #12에서 생성)
- ffmpeg, Homebrew 모두 미설치 확인(이슈 #13과 동일한 제약) — 비디오/배너 팝업 범위 제외의 근거
- SWF 디컴파일 도구(JPEXS 등) 미설치. 단, `xmark_main.fla`는 XFL 형식(zip 압축)이라 타임라인/라이브러리 XML을 직접 읽을 수 있음(이슈 #12와 동일한 상황, 이슈 #13과는 다름)
- mock 데이터 실제 확인 (`project/flash/xmark/src/fla/xml/gallery.xml`, 805줄, `list` 60건):
  - `type` 분포: `image` 27 / `flash` 33 / `banner` 1 — 원본 분석 문서의 "비디오 1개" 추정과 다름(실측 33건)
  - `type="flash"` 전부 `.flv` 확장자만 사용(`.swf`와 혼재하지 않음)
  - `sort` 값은 0~5까지 실측(0이 17건, 1이 19건, 2가 20건, 3이 1건, 4가 1건, 5가 2건) — XML 주석은 0~3만 설명, 4·5는 "준비중"인 gui/mobile 추정
- 코드(`PopUpMain`)는 `type`을 `image`/`video`/`swf`로 처리하는데 XML 실측 값은 `image`/`flash`/`banner` — ③ 스펙 vs 코드 불일치(블로킹 아님, 데이터·필드 정의 섹션에 반영)
- 교차검증 게이트: 디자인 파일 없음(n/a) / 코드 불일치는 위 ③ 1건(01~02 블로킹 아님, 재검증 불필요) → **통과**

## 알려진 한계

- **logo/GNB/util/recruit 원본 이미지**: XFL 내부 비공개 비트맵 캐시(`.dat`) 포맷이라 디코더 없이 추출 불가. 텍스트/CSS로 대체(서브태스크 01, `TROUBLE_SHOOTING.md` 참고).
- **About 콘텐츠**: 원본 `about_container`가 텍스트 없이 100프레임짜리 모션 그래픽 심볼 하나로만 구성되어 있어 추출 가능한 소개 문구가 없음. 설명 텍스트로 대체(서브태스크 07).
- **80타일 전환 구현 방식**: 원본은 `BitmapData.draw`로 콘텐츠를 타일마다 실제로 캡처해 복제하지만, 이 이관은 html2canvas 같은 신규 라이브러리 없이 타일을 배경색과 같은 불투명 "덮개"로 두고 뒤집어 치우는 방식으로 단순화함(서브태스크 07). 시각 효과는 동일.
- **비디오·배너 팝업 재생**: ffmpeg/Homebrew 미설치로 변환 도구가 없어 실제 재생 없이 썸네일+안내 문구만 표시(결정 사항 ②, 서브태스크 06).
- **Ruffle 비교 검수 미실시**: 이번 이관은 Ruffle로 원본을 실행해 녹화하는 대신, 전 서브태스크에 걸쳐 AS3 소스 코드(`Thumb.as`, `ThumbManager.as`, `List.as`, `ListManager.as`, `PopUpMain.as`, `Image.as`, `AboutMain.as`, `ContactMain.as`, `ProjectMain.as`, `XmarkMain.as`)에서 수치(지속시간/이징/지연/좌표)를 직접 추출해 구현함 — 소스 코드가 Ruffle 녹화를 보고 추정하는 것보다 더 정확한 근거라고 판단했기 때문(이슈 #57 PoC에서 같은 판단을 내린 바 있음). 다만 이 때문에 원본 이슈 #52의 "확인 필요 사항" 중 아래 2건은 Ruffle 실행 확인이 전제였던 항목이라 이번 범위에서 해소하지 못하고 열어둠:
  - FLA의 가이드 레이어 72개가 실제 작업용 참고 레이어인지(죽은 레이어 추정) — 소스 코드만으로는 판단 불가
  - `StoryMain`(빈 화면), `Ripple`/`WaveImage`/`Rippler`(라이브러리 심볼 미연결 추정)를 완전히 제외할지 — 이번 이관에서는 애초에 해당 기능들을 구현 범위에 포함하지 않았으므로(Story는 "준비중" 알림만, 리플 효과는 FR에 없음) 실질적으로는 제외된 상태와 같으나, Ruffle로 직접 확인한 것은 아님
