## 결정 로그

- **이관 범위**: `RegionViewManageBoard`(권역조회, 조회 전용) 화면만 이관한다. 세분류 편집(`RegionSubDivision`),
  센터 관리(`RegionCenter`), 버전 관리(`RegionVersion`) 등 인접 편집 화면은 범위 밖.
- **목업 방식**: 백엔드가 없는 프로젝트 제약상, fixture 함수가 Promise로 정적 데이터를 반환하는 방식을 채택
  (MSW 브라우저 워커는 도입하지 않음 — 구현 간단함 우선, 사용자 확정).
- **엑셀 다운로드**: 이번 이관 범위에 포함하되, 서버 blob 대신 클라이언트에서 mock blob을 생성해 다운로드
  동작만 재현한다(사용자 확정).
- **메뉴/라우트**: 메뉴명 "권역조회", 경로 `/region-view`(사용자 확정).
- **카카오맵 키**: 기존 `PolygonMapGuard`(`useKakaoLoader`) 패턴을 그대로 재사용. 라우트 기반이라
  동시 마운트되지 않으므로 `docs/TROUBLE_SHOOTING.md` 2026-10-03 12:50 항목의 옵션 불일치 리셋 이슈는
  해당 없음.
- **문구 통일**: 레거시의 `'상온 only'`(상수 라벨) vs `'상온Only'`(하드코딩) 불일치는 이슈 본문 확인
  필요 사항 #3에 기록, 03/04 착수 시 확정한다.
- **배송센터 옵션 소스**: `getDeliveryCenters` API 목업 vs 하드코딩 상수 중 택일은 이슈 본문 확인
  필요 사항 #4에 기록, 02~03 착수 시 확정한다.
- GitHub 서브이슈로 7개 생성(이슈 본문 체크리스트 아님), Draft PR은 `Closes #11`만 연결.

## 발견 사항 (③ 유형 — 스펙 vs 코드)

- demos 프로젝트에는 아직 axios 클라이언트(`src/api/`), MSW 핸들러, TanStack Query 훅이 전혀 없음
  (`polygon` 기능도 백엔드 호출이 없어 `api/`, `queries/` 폴더가 비어있었음). 이번 작업이 이 프로젝트
  최초의 "서버 호출을 흉내내는" 기능이 되므로, mock 데이터 레이어 설계(03)가 추후 다른 기능의
  참고 패턴이 될 수 있음.

### 01. 진입 플로우 & 레이아웃

- `/region-view` 라우트, `AppLayout` 메뉴, `RegionViewPage`와 정적 레이아웃 컴포넌트
  (`RegionViewMap`, `RegionViewMapGuard`, `RegionViewSearchPanel`, `RegionViewTopBar`) 구현.
  `AppLayout` Content의 24px padding을 상쇄하는 negative-margin 트릭(`regionView.css`)으로
  지도를 전체화면으로 채우고, 좌측 검색패널(350px)·상단 바를 absolute 오버레이로 배치.
- 카카오맵 가드는 `PolygonMapGuard`와 동일한 `useKakaoLoader` 옵션(`libraries: ['drawing']`)으로
  별도 구현(`RegionViewMapGuard`) — 기존 코드를 건드리지 않기 위한 의도적 중복, 추후
  `fowler-refactor`로 공용화 검토 가능.
- antd v6 기준 `Collapse`는 `expandIconPosition` 대신 `expandIconPlacement` 사용.
- 이 워크트리에 `.env.local`이 없어 메인 체크아웃에서 복사해와 카카오맵 로딩까지 직접 확인(사용자 승인).
  로컬 포트 3000이 다른 프로젝트(Drone-OpenSky) dev 서버로 점유돼 있어 카카오맵 허용 도메인을
  벗어났었는데, 사용자가 직접 해당 프로세스를 종료해 포트 3000으로 재검증.
- `pnpm lint` / `tsc --noEmit` / `pnpm test` 통과, `pnpm dev`에서 `/region-view` 레이아웃과
  `/polygon` 회귀 없음을 직접 확인.
