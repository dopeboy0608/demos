단일 서브태스크로 충분한 규모라 서브이슈 분할 없이 진행.

## 결정 로그

- **원인**: `prepare-gyeonggi-boundaries.py`의 `simplify()`가 42개 시/군/구 중 41개에서
  self-intersecting(자가교차) 지오메트리를 만들었음을 `shapely.is_valid`로 확인.
- **해결**: `simplify()` 직후 `geometry.buffer(0)` 추가. 42개 전부 valid가 되고, 면적
  변화는 부동소수점 오차 수준(최대 상대 오차 ~1e-15)으로 사실상 없음을 확인.
- **범위**: 1차 정제(buffer(0))까지만 진행하기로 확정(사용자 승인). 여러 섬이 분리된
  시/군(예: 화성시 8개 조각, 안산시단원구 7개 조각)에서 `splitDongOuterRing`이 가장 큰
  섬만 메인으로 쓰고 나머지를 첫 소분류 조각에 붙이는 기존 한계는 이번 범위 밖 — 추후
  문제가 보이면 별도 이슈로 분리하기로 함.
- **부수 효과**: 자가교차 제거 과정에서 평균 점 개수가 319개/구→67개/구로 더 줄어듦(스퓨리어스
  루프 제거). 파일 크기 228KB→50KB.

## 조사 결과

- Phase B 사실확인: 다른 활성 브랜치가 이 데이터/스크립트 파일을 건드리지 않음(#84 관련
  브랜치는 이미 머지되어 삭제 대상에서 제외).
- 크로스체크 게이트: 디자인 파일 없음(n/a). 코드 확인으로 원인과 해결책을 직접 검증(42개 중
  41개 invalid → buffer(0) 후 0개 invalid, 면적 변화 없음) → 블로킹 항목 없이 게이트 통과.
