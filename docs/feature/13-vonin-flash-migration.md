## 사실 조사 / 발견 사항 (Phase B)

- `src/features`에 "bonin"/"vonin" 네이밍 충돌 없음
- `gsap`, `react-youtube`는 #12에서 이미 설치됨(재사용 가능, 이번엔 react-youtube는 불필요할 수 있음)
- `sub-task` 라벨 기존 존재(이슈 #12에서 생성)
- SWF 디컴파일 도구(JPEXS, ffdec, swftools 등) 전부 미설치 확인
- ffmpeg, Homebrew 모두 미설치 확인
- mock 데이터 실제 확인 (`project/flash/보닌/src/fla/swf/xml/*.xml`):
  - `menulink.xml`: `link` 속성은 URL이 아니라 메뉴 표시 텍스트, 최대 3단계 중첩
  - `main.xml`: `rollproduct.url` 8건(원본 분석 문서의 "9개 상품" 추정과 다름), `bestremark.product` 2건·`rss` 2건·`qa` 2건(원본 분석 문서의 "3건" 추정과 다름), `notice` 3건, `event.slide` 3건, `bm` 3건
- 교차검증 게이트: 디자인 파일 없음(n/a) / 코드 불일치(③) 없음 → **통과** (재검증 불필요)

## 알려진 한계

- **캐러셀 정확한 좌표**: `Contents.as`의 `tgX/tgY` 배열 값은 컴파일된 SWF/FLA 내부에만 있고, FLA가 구형 바이너리(CS3/CS4)라 XFL처럼 직접 읽을 수 없으며 디컴파일 도구(JPEXS 등)도 미설치라 추출 불가. 가로 일렬 배치로 단순화(서브태스크 02).
- **영상 재생**: ffmpeg/Homebrew 미설치로 `movie.flv` → MP4 변환 불가. Player는 재생/일시정지 토글 UI만 구현, 실제 영상 없음.
- **임베디드 한글 폰트**: 13종 식별·라이선스 확인이 필요하나 이번 범위에서는 시스템 기본 폰트로 대체.
- **Ruffle 비교 검수 미실시**: 이슈 #52(xmark)와 동일한 이유로 Ruffle 녹화 대신 AS3 소스 코드에서 수치를 직접 추출하는 방식을 사용.
- **홈↔카페 컷 트랜지션**: 원본은 `cut_mc` 타임라인을 마지막 프레임까지 재생한 뒤 화면을 교체하고 역재생하지만, 해당 타임라인 애셋을 추출할 수 없어 짧은 페이드 아웃→교체→페이드 인으로 단순화(서브태스크 06).
