## 작업 방식

- 서브태스크마다 구현 후 커밋 전에 사용자 확인을 받는다(Phase C 체크포인트).
- 모든 커밋 메시지에 해당 서브태스크 이슈 번호를 포함한다.
- 01 커밋 이후 PR을 열기 전 먼저 확인받는다. PR 설명에는 스토리 이슈(`Closes #33`)만 연결한다.
- 커밋 전 `pnpm lint:fix` / `pnpm format` / `pnpm test` 실행.
- 새로 추가/수정하는 코드는 서브태스크 완료 시 `/code-organizer`로 정리한다.

## 결정 로그

- **배송센터 코드 범위**: 스크린샷엔 더 세분화된 코드(AA, CA, CS 등)가 보이지만, 레거시 하드코딩
  상수 22개(`A, B, BS, C, D, DE, DW, F, G, GC, H, I, M, Q, R, S, T, UL, W, X, Y, Z`)를 그대로
  사용하기로 사용자가 확정(개수·분위기만 비슷하게 맞춤, 1:1 일치는 아님).
- **범위**: 시각적 정밀화(배지/버튼/간격) + 더미 데이터 볼륨 + 줌 버그 수정에 한정. 기존 검증 로직,
  빈 결과 처리 등 정책은 변경하지 않는다.
- Cross-check gate: 이번 작업은 기존 화면의 시각적 정밀화/버그 수정이라 ①/② 유형의 스토리-디자인
  불일치 항목이 없어 게이트 통과(재검증 불필요).

### 01. 배지 및 위치보기 아이콘 버튼 통일

- `RegionViewRegionResult`에 `createRegionGroupColors`를 재사용해 센터 코드 원형 배지(지도
  폴리곤과 동일 색상) 추가.
- `RegionViewRegionResult`/`RegionViewSubRegionResult`의 "위치보기" 버튼을 `shape="circle"` +
  아이콘만 있는 버튼으로 통일, `title="위치보기"`로 접근성 유지.
- `pnpm dev` + 브라우저로 검증: A 센터 배지 색상이 지도 폴리곤과 일치, 센터/소분류 레벨 모두
  아이콘 전용 버튼으로 통일됨을 확인.
- `pnpm lint` / `tsc --noEmit` / `pnpm test`(26개) 통과, `/polygon` 회귀 없음.
